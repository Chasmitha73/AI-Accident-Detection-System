# 🚨 AI Accident Detection System

An accident management web application built using Python, Flask, and SQLite. It allows users to enter accident details, view accident records, search for records by vehicle number, and delete records through a web interface.

## 🌟 Live Demo

🔗 https://ai-accident-detection-system-9tum.onrender.com

## ✨ Features

- 📝 Enter and save accident details
- 📋 View accident records
- 🔍 Search accidents using vehicle number
- 🗑️ Delete accident records
- 📍 Store location and latitude/longitude
- 🕒 Record accident date and time
- 🚨 Display accident alert information
- 🌐 Access the application through a web browser

## ⚙️ How to Run Locally

1. Clone this repository:

   git clone https://github.com/Chasmitha73/AI-Accident-Detection-System.git

2. Open the project folder:

   cd AI-Accident-Detection-System

3. Install dependencies:

   pip install -r requirements.txt

4. Start the Flask application:

   python app.py

5. Open your browser and visit:

   http://127.0.0.1:5000
